# LinkedIn post brief

After manually validating an OSPF resilience lab, I built a Python-based validator to automate network state checks.

The goal is to classify the topology as:

- GREEN: nominal path active.
- YELLOW: degraded state using backup path.
- RED: no valid route.
- INFO: ECMP detected.

Professional angle: Python + networking + NetDevOps + CIS/critical communications mindset.
